## 应用实现

新增 setup_latex / repair_latex，配置档 latex-chinese-math；安装和包更新参数来自固定
清单，模型只选择项目。每个项目有单独的便携工具链，保留已有 main.tex，并交付 PDF、
open-latex-terminal.cmd、compile-latex.cmd。新建项目无源文件时提供已冻结的中文公式
例文；不会替换已有文档。源文件、安装状态、每阶段日志和编译结果均有持久记录。

安装器退出 0 后仍必须核对实际 xelatex 及版本。安装中断或主程序缺失标记为不确定，
禁止另起安装覆盖。修复先编译并读取真实缺失文件，再通过已校验归档映射宏包；仅针对
当前项目修复，最多两轮。未知错误、映射歧义或归档变化保留现场。成功需要两次新目录、
新进程编译，避免旧 PDF 冒充新结果；源文件哈希必须不变。

独立验收重新运行编译器及实际交付的两个启动器，检查系统 PATH、源文件和项目身份，
重开应用后重复检查。宿主机使用另一套 PDF 工具检查文本、页数、字体并渲染成果。
TeX shell escape、自动补包和首行选项解析关闭；不是针对恶意 TeX 的操作系统沙箱。
