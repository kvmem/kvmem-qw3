# 跨设备本地 Computer Use 首版目标

用户授权：2026-10-03。后台使用本地 QW3，不调用顾问。支持 Windows VM、Linux VM、Android 模拟器；macOS/iOS 先保留接口。允许用户同时进行小规模 GPU 测试，只管理本目标创建且确认身份的进程。

## 冻结基线与判断原则

- 修改前基线：`e237c72e2971f281ee7ec76adbe2f840ec9332cf`。Windows client33 的 144/144 合约检查、P3 的 14/16 无接管与 16/16 产物正确保留；这些不是 OSWorld 成功率。
- 复用现有 Windows UIA/Win32 执行器、OSWorld 官方 Linux VM 的 PyAutoGUI/AT-SPI 服务、Android Appium UiAutomator2/ADB。统一核心拥有任务、设备、观察、动作回执、步骤条件、等待和恢复；驱动只负责设备操作。
- Codex 是第一种 agent runtime，模型与设备协议不绑定 Codex 事件格式。默认每个设备只有一个输入所有者，本地模型请求串行。
- 不假定成功率会提高。Windows 历史改编任务与 Linux 官方任务分开报告。Linux 新旧流程使用相同模型、思考模式、DFlash、材料、初态、工具权限与预算。变化包括工具契约与提示词，不能把效果全部归因于模型。
- 工具校验只证明所声明条件成立；业务正确性由独立验收器判断。不能把模型结束发言、鼠标送达、窗口变化视为任务完成。UI 文本不得成为指令或评分答案通道。

## 阶段与退出条件

1. **基线、资源和协议。** 冻结代码/模型/任务版本及材料哈希，记录 GPU 共用与显存，安装工具时清除 HTTP/HTTPS/ALL proxy；实现设备能力、会话/显示身份、观察尺寸与旋转、动作送达和条件验证的分离。既有 Windows 合约测试必须通过。
2. **有完成条件的执行。** 增加声明步骤条件、有界轮询等待、跨 action_id 的重复意图检测、持久步骤记录与恢复检查点。等待不重复输入；相同意图但页码/状态变化可继续。重启不重放不确定动作。无法自动证明完成时明确待核验。
3. **三平台合约。** Windows 保留当前执行器；Linux 接官方 OSWorld VM 服务且网关仅本机监听；Android 接固定版本 Appium/模拟器。验证坐标、焦点、Unicode、滚动/拖动或滑动、观察失效、重启、丢回执、单设备输入锁。只通过合约不算模型任务通过。
4. **三平台真实 QW3 任务。** Windows：Python 新装/修复、LaTeX 新装/修复；Linux：文本创建保存、浏览器表单、Calc 跨单元格编辑；Android：设置查找修改、联系人创建编辑、浏览器多字段表单。各任务两次，全程录屏，独立检查产物/应用状态。Android 只使用测试资料。每平台额外测试慢加载、焦点/弹窗、无进度、回执丢失四类故障；不能证明已送达时停止并保留检查点。
5. **Linux OSWorld 2.0 同条件对照。** 固定本地 `OSWorld-V2` 版本与原任务 `013,004,006,010,038,022,035,043,080,051`，执行前检查材料、服务与 evaluator。每个任务旧流程/新流程各两次，顺序交错；每次 1800 秒、250 次工具调用，QW3 thinking 开、DFlash2 开、KVMem 关、顾问关。预检失败照样进入总表，标记不可评估，不计成模型失败也不换成容易任务。正式试验不读评分规则给 agent，不向模型提供标准答案。纯 GUI 主表；软件工具模式另表。
6. **诊断、优化与复测。** 逐次标注材料/环境、读屏、定位、规划、输入送达、等待、恢复、错误完成。仅依据首轮记录作通用优化，保留所有原失败和基础设施中断。同一任务材料和预算复测，注明是开发集复测；不把它作为陌生任务泛化证据。
7. **KVMem 与交付。** 在预先指定的长任务 035、080 上，新流程 KVMem 开/关各两次，其余配置不变。记录实际上下文长度/检索是否触发；没有触发时不能声称证明了记忆收益。产出新旧连续录像并排回放、逐次结果与汇总、限制与复现说明，以及相关本地代码提交。

## 指标与证据

主指标：官方独立评分/端到端无接管成功率、错误完成率、人工接管率。辅助：任务总时长、推理首 token/总时长、工具耗时 P50/P95、实际输入数/观察数、重复意图拦截数、无进度段时长、故障恢复步数、条件超时、重试与不确定送达、GPU 峰值显存和外部负载、上下文与 KVMem 检索。两次重复只作小样本描述，不宣称统计显著。

每次尝试保留 attempt ID、baseline/candidate 代码哈希、设备镜像/初态、任务材料哈希、模型和引擎配置、累计预算、输入回执、条件证据、独立评分、连续视频。重试新建记录，原中断不覆盖。秘密 token、顾问密钥、完整私有请求不进入公共回放。
