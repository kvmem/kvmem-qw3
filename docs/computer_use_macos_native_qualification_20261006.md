已在用户提供的 Intel Mac（macOS 13.7.7）上完成原生执行端部署及首轮工具验收。

规范化坐标、控件身份和操作回执，Mac 端负责截图、系统控件与输入。

原生程序在 Mac 本机编译、签名检查通过，8 项零输入自检通过；主机侧 9 项 HTTP
边界检查通过，覆盖未知投递不重发、进程重启导致旧截图失效、第二所有者拒绝、
未授权控制和恢复失败时继续暂停。早期编译字典类型错误、沙箱禁止测试绑定临时
端口、使用错误 Python ABI 导致视频库导入失败等准备错误都没有计作模型失败。
已分别修正，保留对应记录。

## 此次实现的保护和限制

录制使用独立 `/frame` 接口，不改变用于执行操作的 `/observe` 截图身份。实测在
录制同时进行时，之前取得的任务截图仍能完成准确点击。这防止录制过程不断让
模型的操作凭据过期，但还没有据此证明复杂任务成功率提高。

录制目标是 1 Hz，实际采样间隔中位数为 2.20 秒，最长为 3.27 秒；当前视频适合
核对状态变化。它只覆盖操作阶段的真实截图采样，不是完整 48 秒的连续录屏。
后续需要单独优化截图编码、传输和录制方式，以便回放精细动作。

目前是独立、可暂停的 Mac 原生适配器，首轮命名应用操作仅支持已准备的 TextEdit，
多显示器、旋转屏幕、拖拽和其他软件仍未实机验收。主应用的 Mac 设备选择、MCP
工具 schema 和完整 QW3 任务尚待接入；本次没有消耗模型推理资源。模型后续继续
运行在现有 Linux GPU 主机，不能宣称已在 Mac 自身硬件上运行。
