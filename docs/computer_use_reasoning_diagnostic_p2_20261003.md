## 题目与控制条件

四类各三题，每类两个开发、一个保留，共 8/4。涵盖顺序报销与总预算、整包精确采购、
磁盘和下载双约束，审批政策版本与生效时间，证件、附件和多材料关联，以及安装不确定
结果的处理、修复步骤排序、基于真实证据的工作簿验收。

12 张截图均在实际 Windows VM 的 Edge 中采集。模型读取前逐张核对：全部任务事实
可见，未被通知遮挡；文字组按相同顺序保留标题、全部规则、事实和干扰项，不提供
解法或额外信息。截图还含任务无关的窗口边框、时钟及广告，因此不是整张桌面逐字
转录。公开 HTML 单独进入客机；标准答案、目标分组和判分只保留在宿主。

固定 Qwen3.8-27B Q8_0、同一视觉编码器、DFlash2 配置、KVMem-off、temperature=0、
top_p=1；两种 thinking 模式使用相同 4096 总输出 token 上限。按预先固定随机顺序
串行运行，保留每次原始请求与 SSE、用量、耗时和评分。答案及条件在请求前冻结；
采购题还通过独立枚举核对唯一最优解。三个测试防止答案泄漏、类型宽松和不完整约束
被误判通过；它们不算模型成绩。
